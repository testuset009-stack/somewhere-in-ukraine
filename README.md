# Десь в Україні

Вікторина по областях України для ТВ (`/`) та пульта ведучого (`/host`).

## Швидкий старт

```bash
npm install
node server.cjs
```

- Екран ТВ: `http://<local-ip>:3000/`
- Пульт ведучого: `http://<local-ip>:3000/host`
- Перевірка стану: `GET /health`

## Особливості

- **Реальна векторна карта України**: 25 регіонів (24 області + АР Крим) на основі geoBoundaries UKR ADM1.
- **Режим «Дві команди (Жовта і Блакитна)»**: швидка дуель жовтої та блакитної команд, а також класичні режими «Команди (2–8)» та «Одна команда».
- **6 українських пакетів питань** (по 25 питань, охоплюють усі 25 регіонів):
  - Цікавинки (`facts_uk.txt`)
  - Загальна історія (`history_uk.txt`)
  - Де народився (історія) (`born_history_uk.txt`)
  - Де народився (зірки) (`born_stars_uk.txt`)
  - Де народився (письменники) (`born_writers_uk.txt`)
  - Де відбуваються події (література) (`literature_places_uk.txt`)
- **Захист секретних відповідей**: `GET /api/state` приховує відповідь під час відкритого питання; опційний PIN-код пульта в налаштуваннях.

## Формат пакетів питань (`.txt`)

```txt
#1 [LV]
Текст питання (1-ша частина)...
+++
Додаткова підказка (2-га частина, ½ очок)
---
Львівська область — коротке пояснення після відкриття
```
